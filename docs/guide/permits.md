# 作业许可

按作业票类别填写资料并完成现场核查和审批，核实开工条件后作业。

## 许可审批前核查与条件准备

<p className="guide-role">办理人：所有用户</p>

1. 按作业类型填写资料、JHA/施工关联、责任人员和气体测量；有限空间填写不少于2人的人数。
2. 正式提交前，由不同人员的双方监工分别完成审批前现场核查。
3. 涉及设施或特殊条件时核对会签和条件批准人；有限空间须有有效的主要负责人或书面委托批准授权。
4. 批准后仍需有效期内双方前检，由本公司监工确认开工。

<p className="guide-note">图中为动火申请资料，核查在单据详情办理；审批前核查不替代开工前检查。</p>

## 外包许可关联批准施工

<p className="guide-role">办理人：申请人</p>

1. 选择外包施工，关联已经批准的施工申请。
2. 施工单位、地点、JHA版本随关联填入，再核对责任人和双方监工。
3. 许可时间必须落在批准的施工周期内。

<p className="guide-note">外包与自营入口不同，不能用自营入口绕过外包施工前置条件。</p>

## 未来外包许可被正确阻止开工

<p className="guide-role">办理人：现场监工</p>

1. 本公司监工打开已经批准的外包许可。
2. 未到许可时间时不能开工，也不能提前完成正式前检。
3. 到有效期内再由双方逐项检查并确认开工。

<p className="guide-note">本次真实点击返回409，批准状态不会绕过许可时间限制。</p>
