# 作业许可

更新日期：2026-10-13

**谁来办理：** 内部申请人填写，双方监工核查，指定岗位按任务审批。

**办理前：** 核对有效JHA、所需施工申请、票种专有资料、检测结果和实际责任人。有限空间还须具备有效企业授权。

**完成结果：** 先完成批准及开工条件确认，再进行现场检查和归档。未批准时不得开工。

审批资格、有限空间企业授权和检测维护权限已集中调整。[查看当前管理设置与操作截图](/management)。

## 15-0 · 许可审批前核查与条件准备

**办理岗位：** 申请人及本次指定的双方监工

1. 按作业类型填写资料、JHA/施工关联、责任人员和气体测量；有限空间填写不少于2人的人数。
2. 正式提交前，由不同人员的双方监工分别完成审批前现场核查。
3. 涉及设施或特殊条件时核对会签和条件批准人；有限空间须有有效的主要负责人或书面委托批准授权。
4. 批准后仍需有效期内双方前检，由本公司监工确认开工。

## 19 · 未来外包许可被正确阻止开工

**办理岗位：** 试用公司监工 · R09 现场监工
