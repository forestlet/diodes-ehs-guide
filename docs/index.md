# 使用指南

按业务查看填写、审批和查询方法。

## 进入系统

[打开网页版](https://8.160.180.140:8443/) · [下载安卓 APP](https://8.160.180.140:8443/downloads/daer-ehs-latest.apk)

电脑、安卓和 iPhone 均可使用网页版；安卓也可下载 APP。已有旧版时直接安装新版，保留原应用。首次安装请按手机提示允许本次安装，安装后重新登录。

当前为测试环境，请使用分配给你的专用测试账号及模拟资料。账号清单单独提供，教程不公开密码。

指南更新：2026-10-19。登录后先在工作台查看本人申请和待办；兼任多个岗位时，在账号菜单切换已授权角色。
