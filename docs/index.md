## 四类表单如何配合

| 业务 | 使用顺序 | 完成后得到什么 |
| --- | --- | --- |
| JHA风险分析 | 分步骤填写 → 指定审核人 → 提交审核 | 可供关联施工或作业许可的已审核风险分析 |
| 施工申请 | 关联已审核JHA → 填写施工资料及条件 → 指定责任人 → 提交审批 | 已批准施工申请；危险作业仍须另办相应许可 |
| 作业许可 | 关联有效JHA及所需施工申请 → 选择票种 → 填写专有资料和检测值 → 现场核查及审批 → 开工与检查 → 归档 | 对应票种的审批、现场检查及归档记录 |
| 变更 | 提交变更及风险判断 → 审批 → 实施与投用确认 → 验收；临时变更还须恢复确认 | 保留申请、实施、验收和恢复记录的闭环单据 |

审批任务由系统按业务、作业票类别及实际条件生成。请按“我的待办”办理，不以本指南中的模拟人员代替实际责任人。

## 每次办理时核对什么

1. 在侧栏底部核对姓名和当前角色。角色切换只改变工作视图，不新增权限。
2. 在“业务办理”中选择表单。带星号的字段必填；不适用内容按表单要求写明理由。
3. 逐项核对指定责任人、关联单据、有效时间和现场条件，再正式提交。
4. 审批人从“我的待办”打开记录，查看表单、风险、附件及已有签核后处理。
5. 查看“全部记录”中的状态、办理意见和历史记录。需要纸质文件时，打开“查看打印件”，打印或另存为PDF。

未批准单据不能作为开工许可。线上批准也不能替代现场条件确认、实时检测和必要的停工措施。
