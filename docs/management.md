# 审批资格与检测维护

更新日期：2026-10-13。以下截图使用模拟人员和教学配置。

## 管理员：指定人员资格与维护范围

1. 使用管理员账号进入“管理后台”。
2. 打开“审批资格与检测权限”，选择人员。
3. 在“个人作业资格”中添加适用申请部门、作业类别、资格结论、有效期和依据。未单独设置时，沿用“岗位默认作业资格”。
4. 需要停止某人办理指定作业时，设为“不具备”。个人授权到期后不能自动退回岗位默认资格。
5. 在“检测规则维护范围”中指定部门、动火或有限空间、有效期和依据。被指定人员须具备该部门EHS工程师或EHS经理岗位权限。
6. 填写调整原因，保存设置。系统记录调整前后的内容及办理人。

![人员审批资格](/images/59c45496d74bcb5a92f6.png)

人员资格是附加条件。办理人仍须满足原有岗位、授权范围、单据责任和本人回避要求。管理员身份本身不提供业务审批资格。设置变化立即用于未办理操作；历史签核保持原记录。

有限空间最终批准人还须在本页下方配置企业主要负责人或书面委托人。普通作业资格不能替代企业授权。授权到期、停用或变更时，按系统提示重新办理相关作业票。

## 指定EHS人员：维护检测规则

1. 使用具备有效维护授权的EHS账号打开“EHS测量设置”。
2. 选择“动火”或“有限空间”，再选择已授权的部门。
3. 按公司批准制度录入检测项目、单位、最低和最高允许值，明确边界值是否包含。
4. 填写制度依据和调整原因，保存设置。两类作业票分别维护，互不覆盖。
5. 申请人和现场人员填写实际测量值。系统按作业票类别读取检测规则，并校验完整性和范围。

![指定检测规则维护](/images/d19cb0d6b45f9ef57c4e.png)

未被指定、授权到期或EHS岗位权限被撤销时，不能保存检测规则。管理员负责指定维护人，不代替专业人员核定限值。

已提交作业票保留当时的限值快照。旧部门共用规则在迁移期间作为兼容来源；对应类别保存独立规则后，优先使用独立规则。正式使用前须分别复核两类作业票的项目、限值及实际作业条件。系统不自动认定教学限值为公司标准。
